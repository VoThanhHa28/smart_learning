----- PROMPT SENT TO LLM -----
You are a professional AI assistant specializing in semantic analysis of educational content.

---

### TASK
You will be given several numbered text chunks, each written like [1], [2], [3], etc.

For EACH chunk, produce one JSON object that describes its semantic meaning.
You MUST return the SAME number of JSON objects as there are input chunks.

At the end, return ONE single JSON array containing all the objects, in the same order as the input.
Do NOT stop until you have included ALL chunk_ids.

---

### OUTPUT FORMAT
Return ONLY ONE valid JSON array.
No markdown, no explanation, no backticks, no text before or after.

Each object must follow this schema:

{
  "chunk_id": <integer>,
  "semantic_tags": ["short lowercase keywords, 1-3 words each"],
  "difficulty": "easy" | "medium" | "hard",
  "knowledge_type": "concept" | "definition" | "example" | "theory"
}

---

### INPUT

[1] Python is an interpreted language widely used in artificial intelligence.
[2] A recursive function calls itself to solve smaller subproblems.
[3] A for loop iterates over elements in a list or collection.
[4] A lambda is an anonymous function often used with map or filter.
[5] List comprehensions provide a concise way to create lists.
[6] Global variables can be accessed from any function but should be used carefully.
[7] A class defines the blueprint for creating objects with attributes and methods.
[8] Modules help organize code into reusable components.
[9] Dictionaries store data as key-value pairs for fast lookups.
[10] The map function applies a function to each element in a list.

---

### FINAL REQUIREMENT
Return a single JSON array with **exactly 10 objects**, each corresponding to a chunk above.
